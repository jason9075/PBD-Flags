Wind Logic

Continuous drive: with wind enabled, every free node receives force input every frame.

Not random: the current wind uses deterministic sine-based functions with row/column phase offsets, so it looks varied without using noise.

Steady: combines a smooth sinusoidal term with a positive gust envelope for a continuous breeze.

Pulse: uses burst-shaped rhythmic gusts, so the flag is driven in repeated packets rather than a smooth stream.

Direction cue: the wind arrow shows the shared visual push direction. The solver applies that force directly into each node's acceleration before the Verlet step.
