Wind Logic

Continuous drive: with wind enabled, every free node receives velocity input every frame.

Not random: the current wind uses deterministic sine-based functions with row/column phase offsets, so it looks varied without using noise.

Steady: combines a smooth sinusoidal term with a positive gust envelope for a continuous breeze.

Pulse: uses burst-shaped rhythmic gusts, so the flag is driven in repeated packets rather than a smooth stream.

Direction cue: the wind arrow shows the shared visual push direction, but the solver still adds scalar velocity into node.speed rather than integrating a full 3D wind field.

Mode Cues

Meaning: these arrows are a cue for the current dominant mode response, not a strict local displacement direction.

How they are built: each cue uses a fixed forward bias plus the dominant mode coefficient, so it is best read as sign and relative strength.

Use it for: spotting which regions participate more strongly in the active mode after an impulse or wind burst.

Mode Explorer

Mode buttons: v1, v2, ... each inject one eigenmode directly so you can isolate that deformation family.

Live Modal Amplitudes: the bars show the current projection onto each mode, which helps compare which responses dominate after wind or pulse input.

How to read it: combine this panel with Impulse, Stiffness, and Mass to see how forcing location and system parameters reshape the mode mix.
